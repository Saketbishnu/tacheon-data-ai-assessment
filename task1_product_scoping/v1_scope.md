# V1 Scope Definition

## What's Included in V1

### Supported Platforms

For the first version, the dashboard supports:

- Google Ads
- Meta Ads
- Google Analytics (GA4)

### Key Metrics Tracked

The dashboard focuses on the most commonly used performance metrics:

- Spend
- Impressions
- Clicks
- CTR
- Conversions
- ROAS

### Main Features

V1 includes the core functionality needed to quickly analyze marketing performance:

- Unified cross-channel dashboard
- Side-by-side channel comparison
- Performance summary overview
- Recommendation section with actionable insights
- Date range filtering

### Recommendation System

Recommendations are generated using simple rule-based logic.

Examples:

- Low CTR → suggest reviewing creatives or ad copy
- High spend with low conversions → suggest budget optimization
- Strong ROAS → suggest scaling high-performing campaigns

---

## Not Included in V1

Some features are intentionally left out to keep the first release focused and manageable.

### AI Forecasting

Not included in V1 because it requires historical data modeling and adds significant complexity.

### Real-time Analytics

Skipped for the initial release to prioritize practical usability over infrastructure complexity.

### Custom Dashboard Builder

Excluded to avoid additional configuration complexity during MVP development.

### Automatic Budget Adjustments

Not included due to the operational risks involved in making automated spending decisions.

---

## Why This Scope?

The goal of V1 is simple: provide a fast and reliable way to understand campaign performance across channels without unnecessary complexity.

The focus is on helping users answer one core question:

**"How are my campaigns performing right now, and what should I pay attention to?"**
